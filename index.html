Zenit Linux nie jest tylko spakowanym jądrem i menedżerem pakietów. zlb (builder) składa cały system z modułów HCL, zpm instaluje i buduje narzędzia ze źródeł, a zpk pakuje wynik — i wszystkie trzy są w środku obrazu, który właśnie budują. Następny Zenit powstaje w Zenicie.

zlb — budowanie Zenit Linux

Jak dystrybucja buduje samą siebie

Cztery etapy, dokładnie te same nazwy, których zlb używa naprawdę we własnym pipeline'ie budowania — nie ilustracja, tylko rzeczywisty proces.

stage0

Bootstrap

Świeży runner pobiera minimalny zpm z own-repository — jedyny moment, w którym Zenit zależy od czegoś spoza siebie.

stage1

Własny ekosystem

zpm instaluje zpm, zpk i instalator — narzędzia budujące resztę systemu są same częścią tego systemu.

stage2

System

Jądro, init (zsrv), bootloader (zboot) i pakiety z modules/*/package.list — każdy z jawnie wybranym backendem lub branchem.

stage3

Obraz

zlb build iso / oci pakuje gotowy rootfs — ten sam obraz, który za chwilę sam zbuduje kolejny Zenit.

Trzy narzędzia, jeden łańcuch

Każde ma jedno zadanie i robi je dobrze — razem tworzą pełny cykl: budowanie systemu, zarządzanie pakietami, publikowanie nowych.

zlb

Zenit Linux Builder

Składa ISO i obrazy OCI z modułów HCL. Bootowalne systemy albo headless kontenery deweloperskie — z tego samego manifestu, dwoma poleceniami.

$ zlb build iso --arch x86_64
Jak działa builder →
zpm

Zenit Package Manager

Jeden front do apt/dnf/pacman/cargo/npm/flatpak i własnego ekosystemu own — instaluje ze źródeł, weryfikuje podpisy, izoluje build w piaskownicy.

$ zpm install kernel -> own -> testing
Poznaj zpm →
zpk

Builder pakietów .zpk

Buduje i publikuje pakiety natywnego formatu .zpk — jednym poleceniem otwiera pull request do rejestru own-repository.

$ zpk build --release && zpk schedule-release
Zobacz zpk →

Zainstaluj zpm na istniejącym systemie

Nie musisz instalować całej dystrybucji, żeby skorzystać z ekosystemu Zenit — zpm działa jako dodatkowy menedżer pakietów obok tego, którego już używasz.

curl -fsSL https://github.com/Zenit-Linux/zpm/releases/latest/download/zpm -o /usr/local/bin/zpm && chmod +x /usr/local/bin/zpm
gotowy obraz, gotowe źródła
