zlb — Zenit Linux Builder

Jeden manifest (distro.hcl), moduły pakietów w HCL i dwa polecenia — zlb składa bootowalne ISO albo obraz kontenerowy OCI. Ten sam builder, który wyprodukował obraz na Twoim pendrive.

zlb build all --arch x86_64

Struktura projektu

Dokładnie to, co znajdziesz w repozytorium zenit — żadnego ukrytego kroku.

zenit/
  distro.hcl                 # manifest główny: nazwa, wersja, architektury
  devcontainer.hcl            # alternatywny manifest -- headless OCI
  modules/
    core/
      package.list             # pakiety systemu (format HCL)
      scripts/setup.janet       # hooki pre/post-install
    devcontainer/
      package.list             # osobny zestaw dla obrazu dev
  installer/
    config.hcl                 # wybór środowisk graficznych, branding
  overlays/
    branding/                  # ikony, banery instalatora
    system/, home/              # pliki kopiowane wprost do rootfs
  keys/
    default.hcl                 # zaufane klucze GPG ekosystemu own

Kilka manifestów, jeden builder

Flaga --manifest pozwala trzymać alternatywne profile budowania w tym samym repo.

ISO

Pulpit

Pełny system z instalatorem graficznym, jądrem i bootloaderem.

$ zlb build iso --arch x86_64
OCI

Devcontainer

Headless obraz deweloperski — bez GUI, bez jądra, tylko narzędzia.

$ zlb build oci --manifest devcontainer.hcl
✓

Walidacja

Sprawdza manifest i wszystkie moduły bez uruchamiania builda.

$ zlb manifest validate
rekurencja, nie metafora

Ten obraz zawiera zlb

Każde wydanie Zenit Linux ma w sobie zlb, zpm i zpk jako zwykłe pakiety own. Widelec repozytorium zenit, zmiana distro.hcl i zlb build all wystarczą, żeby zbudować własny wariant — od zera, tymi samymi narzędziami.
